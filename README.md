# 船舶静水力数值积分计算

[![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

基于数值积分法的船舶静水力要素计算程序，支持梯形法、辛普生第一法、辛普生第二法和乞贝雪夫法，并提供端点坐标修正与增加半站法以提高计算精度。

## 功能特性

- **6种计算方案**：覆盖主流数值积分方法，含端点修正与半站插值
- **完整静水力计算**：水线面面积、漂心、排水体积、浮心坐标、惯性矩、船型系数
- **详细计算报告**：每种方案输出含计算表格的过程报告（TXT）及汇总对比（Excel）
- **端点修正**：直线外推法与抛物线外推法确定水线首尾实际位置
- **增加半站法**：在整数站间插值，提高首尾部曲率变化较大区域的积分精度

## 理论基础

### 数值积分方法

| 方法 | 数学表达式 | 精度 |
|------|-----------|------|
| 梯形法 (Trapezoidal) | $\int_a^b f(x)dx \approx \frac{h}{2}[f_0+2\sum_{i=1}^{n-1}f_i+f_n]$ | 一阶 |
| 辛普生第一法 (Simpson 1/3) | $\int_a^b f(x)dx \approx \frac{h}{3}[f_0+4f_1+2f_2+4f_3+\dots+f_n]$ | 三阶 |
| 辛普生第二法 (Simpson 3/8) | $\int_a^b f(x)dx \approx \frac{3h}{8}[f_0+3f_1+3f_2+2f_3+\dots+f_n]$ | 三阶 |
| 乞贝雪夫法 (Chebyshev) | $\int_a^b f(x)dx \approx \frac{b-a}{n}\sum_{k=1}^{n} f(x_k)$ | $n$阶 |

其中 $x_k = \frac{a+b}{2} + \frac{b-a}{2}t_k$，$t_k$ 为契比雪夫多项式零点。

### 静水力计算公式

| 要素 | 符号 | 公式 |
|------|------|------|
| 水线面面积 | $A_w$ | $A_w = 2\int_{-L/2}^{L/2} y\,dx$ |
| 漂心纵坐标 | $x_F$ | $x_F = \frac{\int xy\,dx}{\int y\,dx}$ |
| 横向惯性矩 | $I_T$ | $I_T = \frac{2}{3}\int y^3\,dx$ |
| 纵向惯性矩 | $I_L$ | $I_L = 2\int x^2y\,dx - A_w \cdot x_F^2$ |
| 排水体积 | $\nabla$ | $\nabla = 2\iint y\,dz\,dx$ |
| 浮心纵向坐标 | $LCB$ | $LCB = \frac{\int xA_s\,dx}{\int A_s\,dx}$ |
| 浮心垂向坐标 | $KB$ | $KB = \frac{\int zA_w\,dz}{\int A_w\,dz}$ |
| 方形系数 | $C_B$ | $C_B = \frac{\nabla}{LBT}$ |

## 快速开始

### 1. 准备型值表

将船舶型值表命名为 `OffsetTable.xlsx`，放入 `OffsetTable/` 文件夹。

型值表格式要求（参考 `demo.xlsx`）：

| 站号 | 型值 | WL1 | WL2 | ... | WL8 | 甲板边线 | ... | 站号 |
|------|------|-----|-----|-----|-----|---------|-----|------|
| -0.5 | \ | \ | ... | ... | ... | ... | ... | -0.5 |
| 0 | \ | ... | ... | ... | ... | ... | ... | 0 |
| 1 | ... | ... | ... | ... | ... | ... | ... | 1 |
| ... | ... | ... | ... | ... | ... | ... | ... | ... |
| 20 | ... | ... | ... | ... | ... | ... | ... | 20 |

- **行**：站号 0~20（21站，20等分），可选半站 -0.5
- **列**：水线 WL1~WL8，对应高度在第三行标注（单位 mm）
- **值**：半宽值（mm），`\` 表示无线型

### 2. 运行计算

```bash
python main.py
```

### 3. 查看报告

报告输出至 `Reports/` 文件夹，包含：
- 每种方案的详细计算过程（TXT 格式）
- 各方案汇总比较报告
- Excel 汇总表（含计算表格）

## 6种计算方案

| 方案 | 积分方法 | 端点修正 | 增加半站 | 说明 |
|------|---------|---------|---------|------|
| 方案一 | 梯形法 | 无 | 无 | 基准方案 |
| 方案二 | 梯形法 | 线性修正 | 无 | 端点直线外推 |
| 方案三 | 辛普生第一法 | 线性修正 | 无 | 抛物线插值积分 |
| 方案四 | 辛普生第一法 | 抛物线修正 | 是 | ★推荐方案 |
| 方案五 | 辛普生第二法 | 线性修正 | 无 | 3/8法则积分 |
| 方案六 | 乞贝雪夫法 | 无 | 无 | 9节点正交多项式 |

### 推荐方案

**方案四**（辛普生第一法 + 端点抛物线修正 + 增加半站法）综合最优：
- 辛普生1/3法则对光滑船体型线具有三阶精度
- 抛物线端点修正准确确定水线首尾实际交点
- 半站法在首尾部提供更密集数据点，显著提升局部精度

设计水线 WL5 (2000mm) 计算结果对比：

| 方案 | Aw(×dL) | xF(站号) | CB | LCB(站号) | KB(mm) |
|------|---------|----------|-----|-----------|--------|
| 方案一 梯形法 | 121,968 | -1.007 | 0.677 | -0.628 | 1282 |
| 方案二 梯形+端点线性 | 121,968 | -1.007 | 0.677 | -0.628 | 1283 |
| 方案三 辛1/3+端点线性 | 121,893 | -1.001 | 0.674 | -0.619 | 1282 |
| **方案四 辛1/3+抛物+半站** | **121,968** | **-1.004** | **0.677** | **-0.629** | **1283** |
| 方案五 辛3/8+端点线性 | 122,162 | -1.005 | 0.677 | -0.621 | 1283 |
| 方案六 乞贝雪夫9节点 | 121,786 | -0.905 | 0.674 | -0.596 | 1283 |

> **注**：表中 `×dL` 表示需乘以实际站距（mm）以获得绝对数值。船型系数（CB, CM, CP, CWP）为无量纲量，不受站距影响。
